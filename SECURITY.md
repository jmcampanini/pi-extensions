# Security Policy


## Reporting a vulnerability

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/jmcampanini/pi-extensions/security/advisories/new).

Do not open a public issue for an undisclosed vulnerability. If private reporting is unavailable, open a public issue asking for a private contact channel without including vulnerability details.

When possible, include the affected extension, the commit you have installed (`git -C ~/.pi/agent/git/github.com/jmcampanini/pi-extensions rev-parse HEAD` for a package install), and steps to reproduce.

Reports are handled on a best-effort basis. There is no guaranteed response, remediation, or disclosure timeline.
